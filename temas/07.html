Tema 7 · Operación del sistema

El sistema operativo reacciona a eventos con interrupciones, protege el hardware usando modo usuario y núcleo, evita bloqueos con un temporizador y se inicia mediante una secuencia de arranque.

1 · Interrupciones

Son avisos que pausan lo que hace la CPU para atender algo urgente: un dispositivo (hardware), una petición del programa (trap) o un error (excepción). Al terminar, todo sigue igual.

2 · Modo dual y Temporizador (Timer)

Las aplicaciones corren en Modo Usuario (Ring 3) sin permisos peligrosos, y el sistema en Modo Núcleo (Ring 0) con control total. Además, un reloj (timer) interrumpe periódicamente para que ningún programa acapare la CPU.

3 · Arranque del sistema (Boot)

Al encender el equipo, el firmware revisa el hardware y pasa el testigo paso a paso hasta abrir el sistema.
