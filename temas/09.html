Gestión de procesos

Tema 9 · Procesos

Un proceso es un programa en ejecución. Mientras que un programa es un archivo pasivo en disco, un proceso es una entidad activa con su propio espacio de memoria, contador de programa, pila y un bloque de control (PCB).
🍳 La receta escrita en un papel es el programa. El acto de estar cocinándola ahora mismo, con tus ingredientes en la mesa y sabiendo en qué paso vas, es el proceso. Dos personas pueden cocinar la misma receta a la vez: serán dos procesos distintos.

1 · Estados de un proceso

Durante su vida, un proceso cambia de estado: Nuevo (creándose), Listo (esperando turno de CPU), Ejecutando (en la CPU), Bloqueado (esperando E/S o un evento) y Terminado (finalizado).

🏥 Como un paciente en el hospital: llega (Nuevo), espera en la sala (Listo), entra a consulta (Ejecutando), va a hacerse una radiografía (Bloqueado) y recibe el alta (Terminado).

2 · PCB (Bloque de Control de Proceso)

El sistema operativo representa cada proceso mediante una estructura de datos llamada PCB (Process Control Block). Guarda su identificador (PID), estado actual, contador de programa, registros de la CPU, información de memoria y archivos abiertos.

📋 El PCB es la ficha médica del proceso: si el médico (CPU) cambia de paciente, anota todo en la ficha para poder continuar exactamente donde lo dejó después.
Ver ejemplo: inspeccionar el estado de un proceso en /proc 
$ cat /proc/self/status | head -8
Name:   cat
State:  R (running)
Pid:    4521
PPid:   3100
VmSize: 8420 kB

3 · Creación y terminación: fork(), exec() y wait()

En sistemas POSIX, fork() crea un proceso hijo duplicando al padre (devuelve 0 al hijo y el PID del hijo al padre). Luego, el hijo suele llamar a exec() para reemplazar su memoria por un programa nuevo, mientras el padre espera con wait().

🐑 fork() hace una fotocopia exacta de ti; luego el clon usa exec() para ponerse otro uniforme y hacer un trabajo diferente.
Ver ejemplo en C: crear un proceso hijo con fork() y execlp() 
pid_t pid = fork();
if (pid == 0) {
    // Estamos en el proceso hijo
    execlp("ls", "ls", "-l", NULL);
} else if (pid > 0) {
    // Estamos en el proceso padre
    wait(NULL); // Esperar a que termine el hijo
}
